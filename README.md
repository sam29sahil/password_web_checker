# ☠️ Horror Password Tool  

A creepy web app built with **Flask** to:  
- 🩸 Check password strength  
- 🔮 Convert password → SHA256 & Bcrypt hash  
- ⚰️ Try to resurrect (crack) SHA256 hashes using `rockyou.txt`  

---

## ⚡ Features
- Password Strength Checker (weak, moderate, strong)  
- SHA256 + bcrypt hashing  
- Dictionary attack demo with `rockyou.txt`  
- Horror-themed UI (Creepster font, blood effects, dark theme)
